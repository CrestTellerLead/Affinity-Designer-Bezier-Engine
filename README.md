## Features

- Advanced vector design templates optimized for rapid logo creation, UI/UX prototyping, and professional illustration workflows.
- Workflow automation scripts and macro actions to streamline repetitive batch exporting, asset generation, and layer organization tasks.
- Custom symbol libraries, color palettes, and gradient mesh presets for enhanced brand consistency and rapid visual styling.
- Quick-switch macros and custom keyboard shortcut profiles for seamless navigation between the Designer, Pixel, and Export Personas.
- Pre-configured export presets (SVG, PDF, PNG, EPS) with automated artboard slicing, color space conversion, and metadata embedding routines.
- Comprehensive documentation and step-by-step setup guides for all included tools, `.afdesign` templates, and modules.
- Integration examples and bridge scripts for the broader Affinity ecosystem (e.g., Affinity Photo, Affinity Publisher via StudioLink) and third-party apps (e.g., Figma, Adobe Illustrator).
- System resource optimization configs for faster canvas rendering, reduced RAM usage, and optimized GPU acceleration during work on complex, multi-layered vector projects.
- Ready-to-use grid systems, typography scales, and layout templates with automated snapping and alignment routines.

## Usage

To utilize the included resources, download the package using the link above and extract the contents to a local directory. Run the provided setup utility (`Setup.exe` or `Install.ps1` / `Install.sh`) to integrate the custom templates, symbol libraries, and macro configurations directly into your Affinity Designer `User` directory. Follow the on-screen prompts to complete the configuration process. For detailed customization and advanced macro usage, refer to the `GUIDE.md` file included in the archive.
